## 🎯 **Visão Geral**

**Cálculo 1** é a disciplina fundamental que introduz os conceitos de **limites**, **derivadas** e **integrais** para funções de uma variável real. É a base matemática essencial para engenharias, física, economia e ciências em geral.

### **Objetivos de Aprendizagem:**

- Compreender rigorosamente o conceito de limite
- Dominar técnicas de derivação e suas aplicações
- Calcular integrais definidas e indefinidas
- Aplicar o cálculo na resolução de problemas práticos

## 💻 **Ferramentas Computacionais**

### **🧮 Software Matemático**

#### **Wolfram Mathematica:**

```mathematica
(* Cálculo de derivada *)
D[x^2 + Sin[x], x]

(* Cálculo de integral *)
Integrate[x^2 + Sin[x], x]

(* Plotar função *)
Plot[x^2 + Sin[x], {x, -5, 5}]
```

#### **MATLAB:**

```matlab
% Definir função simbólica
syms x
f = x^2 + sin(x);

% Calcular derivada
df = diff(f, x)

% Calcular integral
int_f = int(f, x)

% Plotar
fplot(f, [-5, 5])
```

#### **Python (SymPy):**

```python
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

# Definir variável simbólica
x = sp.Symbol('x')
f = x**2 + sp.sin(x)

# Calcular derivada
df = sp.diff(f, x)

# Calcular integral
int_f = sp.integrate(f, x)

# Plotar
sp.plot(f, (x, -5, 5))
```
